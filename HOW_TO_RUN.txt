==============================================================
 AI 빈자리 주차 안내 — 설치·사용 가이드 (Windows / Mac)
==============================================================

 카카오맵에서 목적지를 찾으면 주변 주차장을 보여 주고,
 AI 카메라가 있는 주차장은 빈칸 수와 입구에서 가장 가까운 빈칸까지 안내하는 웹 앱이에요.
 · 지도·검색·길찾기: 카카오 API (인터넷 필요)
 · 빈칸 판정: 직접 학습시킨 AI가 내 컴퓨터 안에서 해요.

--------------------------------------------------------------
 1. 준비물 (처음 한 번만)
--------------------------------------------------------------
 - 컴퓨터: Windows 10/11 또는 Mac, 저장 공간 약 1GB, 인터넷
 - Python 3.12
   · https://www.python.org/downloads/ 접속 → Download Python 3.12.x
   · [Windows] 설치 첫 화면 아래쪽 "Add python.exe to PATH" 를 꼭 체크 → Install Now
     (이걸 안 하면 실행 파일이 Python을 찾지 못해요)
 - 카카오 키 파일 .env  ★ 중요
   · 보안 때문에 zip 안에 들어 있지 않아요. 팀장에게 .env 파일을 따로 받아서
     압축 푼 폴더(run_windows.bat 이 있는 곳)에 넣으세요.
   · 파일 이름은 점으로 시작하는 ".env" 그대로여야 해요 (env.txt 가 되면 안 돼요).
   · 또는 폴더에서 python setup_keys.py 를 실행해 키를 직접 입력해도 돼요.
   · .env 가 없으면 지도 대신 "카카오 지도 키가 필요해요" 안내가 나와요.

--------------------------------------------------------------
 2. 설치와 실행 — Windows
--------------------------------------------------------------
 1) 받은 parking-finder-app.zip 에서 오른쪽 클릭 → "압축 풀기"
    · 경로에 한글이 없는 곳을 추천해요. 예) C:\parking-finder
 2) .env 파일을 그 폴더에 넣기
 3) run_windows.bat 을 더블클릭
    · "Windows의 PC 보호" 창 → "추가 정보" → "실행"
    · 처음에는 필요한 프로그램을 설치해요. 5~10분 걸려요.
    · 이전 버전을 설치했던 컴퓨터도 새로 필요한 것만 추가로 설치해요.
    · 방화벽 창이 뜨면 "허용"
 4) 잠시 후 브라우저에 카카오맵 화면이 열려요.
    · 안 열리면 주소창에 http://localhost:8000
    · 주소는 꼭 localhost:8000 으로 (127.0.0.1 로 열면 카카오가 지도를 막아요)
 5) 끝낼 때: 검은 창(명령 프롬프트)을 닫으면 돼요.

--------------------------------------------------------------
 3. 설치와 실행 — Mac
--------------------------------------------------------------
 1) zip 파일을 더블클릭해서 풀고 .env 파일을 폴더에 넣어요.
 2) run_mac.command 를 더블클릭
    · "확인되지 않은 개발자" 경고 → 파일에서 오른쪽 클릭 → 열기 → 열기
 3) 브라우저에서 http://localhost:8000 이 열려요.
 4) 끝낼 때: 터미널 창에서 Ctrl + C

--------------------------------------------------------------
 4. 사용법 (시연 순서)
--------------------------------------------------------------
 1) 첫 화면: 카카오 지도
    · 빨간 P = 일반 주차장 (카카오 정보)
    · 초록 "P 빈칸 6/13" = AI 카메라가 있는 주차장 (지금 빈칸 / 전체 칸)
 2) 위쪽 "어디로 갈까요?"에 목적지 입력 → 목록에서 고르기
    · 예) 순천대 70주년기념관
    · 아래 패널에 목적지 주변 주차장 목록이 나와요.
 3) "출발지"에 출발지 입력 → 고르기 (◎ 버튼 = 내 위치)
    · 예) 순천역
    · 파란 경로, 걸리는 시간, 거리, 회전 안내가 나와요.
 4) 초록 AI 주차장 핀 누르기
    · 사진 위 초록 칸 = 빈칸, 빨간 칸 = 주차됨
    · "입구에서 가장 가까운 빈칸은 ○번 칸" + 노란 선(입구→칸 길)
 5) "빈칸까지 안내 시작" → "▶ 모의 주행으로 안내 보기"
    · 파란 점이 경로를 따라 움직이고 위쪽에 "1.0km 왼쪽 방향" 같은 안내가 나와요.
    · 도착하면 그 순간의 빈칸 사진과 추천 칸을 다시 보여 줘요.
 ※ 지금은 실시간 CCTV가 없어서 미리 찍은 사진/녹화 영상으로 빈칸을 판정해요.

--------------------------------------------------------------
 5. 관리자 화면 (주차장 등록·칸 그리기)
--------------------------------------------------------------
 run_admin_windows.bat (Mac: run_admin_mac.command) → http://localhost:8501
 지도 화면과 동시에 켜도 돼요.

 [주차장 설정 탭] — 새 주차장 등록
 1) "새 주차장 만들기" → 영문 ID, 이름, 위도·경도
 2) 차가 없는(또는 적은) 주차장 사진을 기준 사진으로 올리기
 3) 사진 위에 표시
    · 칸 추가: 칸 모서리에서 반대쪽 모서리까지 드래그
    · 기울어진 칸: 꼭짓점 4개를 차례로 클릭
    · 입구: 입구 위치 클릭
    · 통로: 차가 다니는 길을 드래그 → "경로 미리보기"로 확인
 4) 모두 자동 저장돼요. 관리자 화면 [빈자리 안내 탭]으로 돌아가 확인하세요.

 [판정 방식] (왼쪽 설정)
 · 칸 분류 AI (추천) : 직접 학습시킨 AI. 실제 CCTV 사진 정확도 99% 이상
 · 나머지 방식은 비교용이에요.

--------------------------------------------------------------
 6. 문제가 생기면
--------------------------------------------------------------
 · "카카오 지도 키가 필요해요"
   → .env 파일이 폴더에 없어요. 1번 준비물 참고 → 검은 창 닫고 다시 실행
 · "카카오 지도를 불러오지 못했어요"
   → 주소가 http://localhost:8000 인지 확인 (127.0.0.1 X)
   → 계속 안 되면 팀장에게: 카카오 개발자 사이트의 JavaScript SDK 도메인 확인 요청
 · 검색·길찾기가 안 돼요 → 인터넷 연결 확인
 · "Python이 설치되어 있지 않아요"
   → Python 설치 때 "Add python.exe to PATH"를 체크했는지 확인
   → 안 했으면 Python 설치 파일을 다시 실행 → Modify 또는 재설치 후 컴퓨터 재시작
 · 설치 중 오류
   → 인터넷 연결 확인 → 폴더 안의 .venv 폴더 삭제 → run_windows.bat 다시 실행
 · "address already in use" / "Port ... is already in use"
   → 이미 켜져 있어요. 이전 검은 창을 닫고 다시 실행
 · 폴더 경로에 한글이 있어서 오류
   → C:\parking-finder 처럼 영어 경로로 옮겨서 다시 실행

--------------------------------------------------------------
 7. 폴더 안 주요 파일
--------------------------------------------------------------
 run_windows.bat / run_mac.command   : 카카오맵 화면 설치 + 실행 (메인)
 run_admin_windows.bat / _mac.command : 관리자 화면 실행
 web/server.py, web/static/          : 카카오맵 화면과 API 서버
 app.py                              : 관리자 화면
 mini.py, mini_template_A3/A4.pdf    : 실시간 미니 주차장 (도안·판정)
 classifier.py, onnx_models.py       : 직접 학습시킨 칸 분류 AI 실행
 occupancy.py                        : 빈칸 판정, 경로, 흔들림 보정
 models/                             : AI 모델 (ONNX)
 data/lots/                          : 주차장 설정과 사진
 .env                                : 카카오 키 (다른 사람에게 공개 금지)
